# IDHAR UDHAR – Production Deployment & Infrastructure Cost Estimate

## 1. Project Scope

The production deployment will include the complete IDHAR UDHAR platform:

* Customer Mobile Application
* Rider Mobile Application
* Admin Web Panel
* Production Backend / REST API
* Production PostgreSQL Database
* Rider Document & Proof-of-Delivery Storage
* Google Maps & Location Services
* OTP / SMS Services
* Push Notifications
* Online Payment Gateway
* Background Workers & Queues
* Security & Access Management
* Monitoring & Error Logging
* Database Backups & Disaster Recovery
* Domain, SSL & DNS
* Google Play Store Deployment
* Apple App Store Deployment

The infrastructure will be designed initially for approximately **5,000–10,000 customers** and will be scalable progressively toward **100,000+ customers** without requiring a complete change of the underlying architecture.

---

# 2. Recommended Production Architecture

The recommended production architecture will use **Amazon Web Services (AWS)** as the primary cloud infrastructure.

### Core Architecture

```text
Customer App
       │
Rider App
       │
Admin Web Panel
       │
       ▼
   HTTPS / SSL
       │
       ▼
Application Load Balancer
       │
       ▼
AWS ECS + Fargate
(NestJS Backend + Workers)
       │
       ├──────────────► Redis / Cache
       │
       ├──────────────► SQS / Background Jobs
       │
       ▼
Amazon RDS PostgreSQL
       │
       ▼
Amazon S3
(Rider Documents / POD / Images)
```

### External Services

```text
Google Maps Platform
MSG91 / SMS Provider
Firebase Cloud Messaging
Payment Gateway
Google Play Store
Apple App Store
```

# 14. AWS Account & Payment Model

AWS uses a **Pay-As-You-Go** billing model for the recommended infrastructure.

There is no requirement to purchase a fixed ₹20,000, ₹50,000 or ₹1,00,000 monthly plan.

The monthly bill is generated according to actual resource usage.

Examples:

```text
RDS
→ Database instance/resources used

ECS/Fargate
→ CPU + Memory + running time

S3
→ Storage + requests + data transfer

CloudFront
→ Data transfer + requests

WAF
→ Requests + rules

Redis
→ Selected capacity/usage

CloudWatch
→ Logs + metrics
```

### AWS India Payment Methods

Depending on the AWS India billing setup, supported payment methods include:

* Credit Card
* Debit Card
* Visa
* Mastercard
* American Express
* RuPay
* Net Banking
* UPI

For production deployment, it is recommended that the **client/company own the AWS account and billing account** rather than keeping production infrastructure under a developer's personal AWS account.

# 18. Important Cost Consideration

The platform will **not be provisioned for 100,000 customers from day one**.

Instead, the system will be architected for future scalability and infrastructure resources will be increased progressively.

For example:

```text
5,000 Customers
      ↓
Initial Production Infrastructure
      ↓
10,000 Customers
      ↓
Increase Backend / DB / Cache Capacity
      ↓
25,000 Customers
      ↓
Horizontal Scaling + Additional Resources
      ↓
50,000 Customers
      ↓
Database / Worker / Cache Scaling
      ↓
100,000+ Customers
      ↓
Advanced High-Availability & Scaling
```

This approach avoids unnecessary infrastructure expenditure during the initial launch while ensuring that the architecture is capable of supporting future growth.

## Final Recommendation

For the initial production launch, the recommended approach is:

**AWS + Amazon RDS PostgreSQL + ECS/Fargate + Redis + S3 + CloudFront + ALB + WAF + CloudWatch + Route 53 + AWS Secrets Manager + SQS/Workers**

combined with:

**Google Maps + MSG91/SMS + Firebase FCM + Payment Gateway**

The system should start with a **₹30,000–₹50,000/month operating budget** and scale infrastructure progressively as customer count, rider count, order volume and API usage increase.

> **Note:** All amounts above are approximate planning estimates. Actual charges are subject to the respective service provider's current pricing, taxes, exchange rates, actual consumption and commercial plans.
